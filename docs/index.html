Características

Todo lo que esperas de tu terminal, con pestañas con nombre, temas y búsqueda.

💻

Una shell de verdad

Cada pestaña es una pseudo-terminal (ConPTY en Windows). Funcionan los colores y los programas interactivos como node, python o vim, y las variables y el directorio se mantienen entre comandos.

🗂️

Pestañas con nombre

El título sigue al directorio actual. Con doble clic o F2 le pones un nombre propio que se mantiene aunque cambies de carpeta.

🐚

La shell que prefieras

Detecta las que tienes instaladas: Windows PowerShell, PowerShell 7, cmd, Git Bash y WSL en Windows; zsh, bash y fish en macOS y Linux. Abre cada pestaña con la que quieras y elige la de por defecto.

♻️

Retoma donde lo dejaste

Al volver a abrirla recupera tus pestañas con su shell, su nombre y su directorio. Se puede desactivar en Archivo › Restaurar Pestañas al Abrir.

⛔

Ctrl+C y cierres seguros

Ctrl+C interrumpe el comando en curso (o copia, si hay texto seleccionado). Si cierras una pestaña o la ventana con algo en marcha, como un servidor, te pregunta antes.

🔗

Enlaces clicables

Las URLs de la salida (por ejemplo http://localhost:3000) se abren en el navegador con Ctrl+clic.

🔍

Búsqueda en la salida

Ctrl+F resalta las coincidencias en la pestaña activa, con contador y saltos con Enter / Mayús+Enter.

🎨

Temas y colores

Oscuro, Claro, Monokai, Solarized, Retro y Hacker. También puedes elegir tus propios colores de fondo, texto, cursor y selección. La barra de título, con los botones de la ventana, se adapta al tema.

⌨️

Lo de tu shell, intacto

Autocompletado con Tab, historial con ↑ ↓ y tu perfil o configuración de siempre (en PowerShell, PSReadLine con historial entre sesiones).

Atajos de teclado

Atajo Acción
Ctrl+T Nueva pestaña
Ctrl+W Cerrar pestaña (también al escribir exit)
Ctrl+Tab · Ctrl+Shift+Tab Pestaña siguiente · anterior
F2 · doble clic en la pestaña Renombrar pestaña (vacío = título automático)
Ctrl+C Copiar si hay texto seleccionado; si no, interrumpir el comando
Ctrl+V · clic derecho Pegar (clic derecho con texto seleccionado lo copia)
Ctrl+F Buscar en la salida (Esc para cerrar)
Ctrl+= · Ctrl+- · Ctrl+0 Aumentar · reducir · restablecer el tamaño del texto
Ctrl+clic en una URL Abrirla en el navegador

En macOS se usa Cmd en lugar de Ctrl, salvo Ctrl+Tab para cambiar de pestaña y Ctrl+C para interrumpir.

Shell en cada sistema

  • Windows PowerShell
  • PowerShell 7
  • Símbolo del sistema (cmd)
  • Git Bash
  • WSL
  • zsh · bash · fish
  • 256 colores · truecolor

Solo aparecen las que estén instaladas. WSL aparece si tiene al menos una distribución. En macOS las shells se abren como shell de login (cargan ~/.zprofile).

Notas de instalación

🪟 Windows

SmartScreen puede avisar de que el editor es desconocido porque el instalador no está firmado. Pulsa Más información → Ejecutar de todas formas.

🍎 macOS

Si Gatekeeper bloquea la app, ábrela con clic derecho → Abrir, o ejecuta xattr -cr "/Applications/HYPE Terminal.app".

🐧 Linux

Dale permisos de ejecución al AppImage: chmod +x HYPE-Terminal-*.AppImage y lánzalo con doble clic.

Compilar desde el código

git clone https://github.com/cmurestudillos/hype-terminal.git
cd hype-terminal
pnpm install

pnpm start           # ejecutar en desarrollo
pnpm package:win     # generar instalador de Windows
pnpm package:mac     # generar imagen de macOS
pnpm package:linux   # generar AppImage

Requisitos: Node.js 22.12+ y pnpm 11+. En Linux, pnpm install compila el módulo nativo de la terminal (node-pty) y necesita python3, make y g++; en Windows y macOS se usan binarios precompilados. Los instaladores se generan en release/.

Documentación

Guía de uso

Ventana y menú

Las pestañas ocupan la barra de título, como en Windows Terminal: arrastra la ventana desde el hueco libre junto a ellas (doble clic maximiza). En Windows y Linux el menú de la aplicación está en el botón ☰; en macOS, en la barra de menús del sistema.

Pestañas y shells

Cada pestaña arranca su propia shell en tu carpeta personal. Ctrl+T o el botón + abren la shell por defecto; el botón ▾ o Archivo › Nueva Pestaña con te dejan elegir otra, y Archivo › Shell por Defecto cambia la de siempre. Cierra pestañas con Ctrl+W, con la × o escribiendo exit; si cierras la última, se abre una nueva.

Restaurar pestañas

Al cerrar la aplicación se guardan las pestañas abiertas: shell, nombre y directorio. Al volver a abrirla se recuperan (los comandos que estuvieran en marcha no). Si un directorio ya no existe, la pestaña se abre en tu carpeta personal. Se desactiva en Archivo › Restaurar Pestañas al Abrir.

Comandos en marcha

Si cierras una pestaña o la ventana mientras un comando sigue en marcha (un servidor, un build, un REPL…), HYPE Terminal te pide confirmación. Al cerrar, se terminan también sus procesos hijos.

Nombres de pestaña

Con PowerShell, cmd, Git Bash y bash, el título muestra el directorio actual. Haz doble clic en la pestaña o pulsa F2 para ponerle un nombre: Enter lo guarda, Esc cancela y dejarlo vacío vuelve al título automático. Al pasar el ratón ves el nombre y el directorio.

Copiar, pegar, interrumpir y enlaces

Selecciona texto con el ratón y pulsa Ctrl+C o clic derecho para copiarlo. Sin selección, Ctrl+C interrumpe el comando en curso. Pega con Ctrl+V o clic derecho. Las URLs http y https se subrayan al pasar el ratón y se abren con Ctrl+clic.

Buscar

Ctrl+F (o Editar › Buscar) abre la barra de búsqueda de la pestaña activa. Si tenías texto seleccionado, se busca directamente. Enter y Mayús+Enter saltan entre coincidencias; Esc cierra la barra.

Temas, colores y texto

En el menú, Ver › Temas cambia entre Oscuro, Claro, Monokai, Solarized, Retro y Hacker. En Ver › Personalizar Colores eliges fondo, texto, cursor y acento, y selección. Al elegir un tema del menú se descartan los colores personalizados. El tamaño del texto se ajusta con Ctrl+=, Ctrl+- y Ctrl+0. Todo se recuerda al volver a abrir la aplicación.

Limitaciones conocidas

  • zsh y fish El título automático y el directorio restaurado dependen de que tu configuración publique el directorio (oh-my-zsh lo hace); si no, la pestaña muestra «Terminal N» y se restaura en tu carpeta personal.
  • WSL Las pestañas de WSL se restauran con su shell, pero no con su directorio.
  • PowerShell 5.1 cd - no existe en Windows PowerShell (sí en PowerShell 7 y en bash).
  • Firma Los instaladores no están firmados (avisos de SmartScreen y Gatekeeper).
  • macOS Solo hay versión para Apple Silicon.

Arquitectura

├── main.js       # proceso principal: ventana, menú, shells y una pseudo-terminal (node-pty) por pestaña
├── preload.js    # puente IPC seguro (contextIsolation activo)
├── renderer.js   # interfaz: pestañas, xterm.js, búsqueda, temas y colores
├── index.html    # estructura de la ventana
└── styles.css    # temas mediante variables CSS

Construida con Electron, node-pty para las pseudo-terminales y xterm.js para mostrarlas. Sin frameworks de UI: HTML, CSS y JavaScript.
